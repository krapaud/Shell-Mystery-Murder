# Dossier d'enquête

Les exports sont fictifs et volontairement désordonnés. Plusieurs actions sont
légitimes. Familles disponibles : `incident/`, `identity/`, `logs/`, `git/`,
`permissions/` et `team/`. Certaines traces décrivent le même événement avec
des niveaux de détail différents : reliez les heures, les terminaux et les
identifiants avant de conclure.

Conservez les identifiants et les heures. Ne concluez jamais avec un seul
fichier. Le nom d'un commit ou le propriétaire d'une credential ne suffit pas
à identifier l'acteur présent au terminal.
